# Fonts

Marcellus Regular and Raleway Variable are included to match the personal site's typography without third-party font requests.

Sources: https://github.com/google/fonts/tree/main/ofl/marcellus and https://github.com/google/fonts/tree/main/ofl/raleway

The original font files are unmodified. See `Marcellus-OFL.txt` and `Raleway-OFL.txt` for their SIL Open Font Licenses and copyright notices.
